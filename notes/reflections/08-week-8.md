# Refleksi Minggu 8

Audit membuat saya membedakan artefak yang tersedia dengan proses yang benar-benar sudah terjadi. File workflow membuktikan konfigurasi CI tersedia; hasil run GitHub Actions dan review pasangan memerlukan bukti tersendiri.

Review yang dapat dipertanggungjawabkan mencantumkan observasi, dampak, usulan, dan hasil verifikasi. Bug fungsional serta pelanggaran layer memerlukan request changes. Preferensi penamaan atau style dapat menjadi saran dan sebagian bisa ditangani formatter.

Klaim bahwa AddNote belum men-trim judul ditolak untuk kode saat ini karena implementasi dan test sudah memuat validasi itu. Perbaikan konkret dari audit ini adalah memperluas CI ke tujuh aplikasi dan menghapus klaim approval/merge yang belum memiliki bukti.

Refleksi ini adalah draf pembelajaran dari audit AI. Refleksi pribadi pasca-review sejawat perlu ditambahkan mahasiswa setelah proses tersebut dilakukan, beserta tautan PR dan dampak perbaikannya.
