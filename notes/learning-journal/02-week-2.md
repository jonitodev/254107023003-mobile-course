# Learning Journal — Minggu 2

- `StatelessWidget` untuk UI dari konfigurasi parent; `StatefulWidget` untuk data yang berubah (mode tema).
- `LayoutBuilder` membaca lebar aktual, lalu memilih 1 atau 2 kolom.
- `CupertinoSwitch` bisa hidup di dalam `MaterialApp` jika kebutuhan UX-nya jelas.
- `Theme.of(context)` menggantikan warna hardcode agar dark mode tetap terbaca.
- Widget test bisa men-override `tester.view.physicalSize` untuk mensimulasikan ponsel dan tablet.
